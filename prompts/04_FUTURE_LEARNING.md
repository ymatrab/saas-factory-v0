# Prompt — Learn from a completed SaaS build without bloating the factory

Use this after a meaningful build/improvement cycle.

---

Review the work we just completed and identify only NEW reusable lessons worth adding to the SaaS Factory.

Do not summarize the project. Do not add generic best practices. Do not duplicate existing factory rules.

For each candidate lesson answer:
1. What happened?
2. Is this reusable across future simple SaaS products?
3. Is it a rule, agent rule, skill/procedure, anti-pattern, or acceptance criterion?
4. Which existing factory file should contain it?
5. Would storing it reduce future mistakes or token usage enough to justify permanent context?

Reject lessons that are:
- project-specific
- obvious one-off bugs
- already covered
- speculative
- too verbose for their value

Then propose a minimal patch only. Do not edit until I ask you to apply it.
