# Learning Imports

Save the output of the Makecepeit extraction as, for example:
- `MAKECEPEIT_LEARNINGS.md`

Save the PayDocs extraction as:
- `PAYDOCS_LEARNINGS.md`

Then run `/prompts/03_INTEGRATE_LEARNINGS.md` from Claude Code in this factory folder.

These import files are staging material. Once their useful lessons have been integrated and reviewed, they do not need to remain in permanent Claude context.
