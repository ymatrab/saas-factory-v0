# Marketing Skill

## Messaging pass (new product or page)
1. Read PROJECT.md: target user, core action, monetization, existing messaging.
2. Define in ≤10 lines: audience, top 3 pains, outcome promise, proof available (real only), top 3 objections, primary CTA.
3. Write page copy section by section: goal → headline (≤10 words) → subhead → body → CTA. Give 2–3 headline variants for the hero.
4. Check every claim against real product behavior and the capability module (rules/product.md).
5. Write the typography/hierarchy brief: headline/body scale, max line length, CTA prominence, what must be above the fold on mobile.
6. Save accepted messaging to PROJECT.md "Messaging & conversion"; hand copy blocks to design.

## Conversion review (live page)
Run `cro` on the URL, list the top 5 fixes ranked by expected impact, and fix copy directly; route layout changes to design.
